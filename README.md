# Турник

Нативное Android-приложение для учёта подтягиваний. Данные хранятся локально.

## Автообновления без магазинов
Приложение проверяет GitHub Releases при запуске и по кнопке «Проверить обновления». При наличии новой версии предлагает скачать APK и открыть системный установщик. Android требует подтверждения установки.

## Однократная настройка постоянной подписи
В репозитории открой Settings → Secrets and variables → Actions → New repository secret.
Создай два секрета:
- `TURNIK_KEYSTORE_B64`: base64-содержимое личного файла с ключом
- `TURNIK_KEY_PASSWORD`: пароль ключа

Не публикуй значения секретов в репозитории. Сохрани файл ключа и пароль: без них нельзя будет выпустить совместимое обновление.

Затем открой Actions → Build Android APK → Run workflow. Если оба секрета установлены, workflow соберёт подписанный APK и создаст GitHub Release с тегом версии (например, v1.1.0). Новые версии должны увеличивать versionCode и versionName в app/build.gradle.

### Установка
Скачай `turnik.apk` из GitHub Releases. Это первая версия с постоянной подписью. Старые debug-сборки могут требовать удаления перед установкой, что может удалить данные. Все будущие релизы с тем же ключом будут обновляться поверх установленного приложения.

GitHub Actions также собирает тестовый debug APK, но **не используй его для обычных обновлений**: он подписан временным ключом и может конфликтовать с установленной версией.
